# Fasrun 帆驭

**[fasrun.dev](https://fasrun.dev)**

帆驭 (Fasrun) 是一套 Spec 驱动的面向软件交付团队的 AI Agent 控制平面与运行时基础设施。它通过 Fasfile 将企业治理公理与安全约束（Guardrails）代码化，为自主 Agent 提供确定性执行保障。

Fasrun is a spec-driven control plane and runtime guardrails for autonomous AI agents.

The repository is being bootstrapped. Development follows the specs under `fasrun/`; the repository's own configuration is in `fasrun.yaml` and its long-term constraints are in `Fasfile`. See [CONTRIBUTING.md](CONTRIBUTING.md) before contributing.
