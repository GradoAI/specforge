## 用户场景

### US-1 标准并发测试消费稳定产物（P1）
作为维护者，我要 CLI 测试与迁移检查在构建成功后消费同一输出，避免一个任务清理另一个任务正在读取的入口。
独立验证：检查真实任务图与构建生产者；冷构建、强制无缓存及缓存恢复分别验证消费者前置，并用有界调度控制复现原清理窗口、验证修正后的顺序。构建失败必须阻止消费者运行。
实现它的需求条目：R-platform-001

### US-2 单独执行 CLI 测试有明确前置（P1）
作为开发者，我要单独运行 CLI 测试时有可执行的构建前置入口，不依赖偶然存在的旧 dist。
独立验证：按文档从无产物目录执行单包测试，检查自身及上游构建前置；入口不能在另一个消费者运行时隐式清理共享输出。
实现它的需求条目：R-platform-001
